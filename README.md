# Ringjahr — Website

Die öffentliche Seite zum iOS-Spiel **Ringjahr**, einem Puzzle über Jahresringe.

Live: https://minh.systems/Ringjahr/

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html`, `en/index.html` | Startseite, deutsch und englisch |
| `datenschutz.html`, `en/privacy.html` | Datenschutzerklärung — die URL, die App Store Connect und AdMob verlangen |
| `support.html`, `en/support.html` | Support-Kontakt und FAQ |
| `styles.css` | gemeinsames Stylesheet, hell und dunkel |
| `assets/` | App-Icon und Screenshots |

Statisches HTML ohne Build-Schritt, ohne externe Abhängigkeiten, ohne Tracking.
Die Seite folgt dem Erscheinungsbild des Systems (`prefers-color-scheme`).
